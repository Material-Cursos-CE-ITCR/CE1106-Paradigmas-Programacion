# Ejercicios: patrones de diseño

## 1. ¿Qué patrón utilizarías? (5 min)

Para cada situación, identifica un patrón, su intención y una ventaja:

1. Una aplicación intercambia algoritmos para calcular costos de envío.
2. Se integra una biblioteca de pagos con una API incompatible.
3. Se necesita auditoría opcional y combinable de un servicio.

## 2. Sistema de pedidos (8 min)

Diseña un sistema que aplique descuentos según tipo de cliente, notifique cambios en los pedidos, utilice una pasarela externa incompatible y coordine inventario, pago y factura.

**Entrega:** diagrama de clases UML con interfaces principales y breve justificación de cuatro patrones. No se requiere código.

## Discusión final (2 min)

¿En qué momento un patrón hace el diseño más complejo de lo necesario? ¿Qué principios SOLID favorecen las soluciones propuestas?
