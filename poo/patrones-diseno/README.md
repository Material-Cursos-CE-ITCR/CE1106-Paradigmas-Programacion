# POO — Patrones de diseño

Tema de **CE1106 Paradigmas de Programación**. La clase introduce 8 patrones de diseño con énfasis conceptual, UML, SOLID y selección justificada.

**Duración:** 120 minutos. **Prerrequisitos:** POO y SOLID. **Ejemplos:** C#.

## Materiales

- [Presentación conceptual (32 diapositivas, Marp)](presentacion.md): sin código C# dentro de las diapositivas.
- [Ejercicios para estudiantes](ejercicios.md): actividades sin respuestas.
- [Ejemplos C# independientes](codigo/README.md): implementación de los ocho patrones y cómo ejecutarlos.

## Patrones

| Creacionales | Estructurales | Comportamiento |
|---|---|---|
| Factory Method, Builder | Adapter, Decorator, Facade | Strategy, Observer, Command |

## Distribución

Introducción (15 min), creacionales (24 min), estructurales (30 min), comportamiento (36 min), ejercicios y cierre (15 min).

## Presentar

Abrir `presentacion.md` con **Marp for VS Code** y exportar a PDF o PPTX. Los diagramas son esquemas conceptuales; se recomienda complementarlos en clase con UML formal.

Referencia: https://refactoring.guru/es/design-patterns. Textos, esquemas y ejemplos de este tema son originales.
