# Ejemplos de patrones en C#

El código está **fuera de la presentación**. Un proyecto de consola sin dependencias externas muestra ocho ejemplos aislados con sus propios espacios de nombres.

## Requisitos y ejecución

- SDK de .NET 8 o posterior compatible.
- Ejecutar desde este directorio: `dotnet run`.

Para ejecutar un solo ejemplo: `dotnet run -- factory`, `builder`, `adapter`, `decorator`, `facade`, `strategy`, `observer` o `command`.

## Alcance

Los ejemplos están diseñados para mostrar las relaciones esenciales, no para simular servicios productivos. Las clases de pago, inventario y factura no gestionan transacciones reales.
